# Relationship to HU-RIZON

This repository is the **public teaching companion** to the HU-RIZON wild-bird AMR project.

The workshop deliberately uses published/public datasets so that participants can reproduce the exercises and revisit them after the course. Unpublished HU-RIZON metagenomes, sample metadata and project results should remain in the project data store and research workflow rather than this teaching repository.

Research repository: https://github.com/HU-RIZON-AMR-BIRDS/HU-RIZON
