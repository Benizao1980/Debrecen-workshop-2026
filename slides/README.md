# Slides

The workshop materials in this repository are aligned to the **36-slide `pubMLST_intro_WB` deck actually delivered in Debrecen**.

The deck follows the Mourkas et al. (2024) 700-genome wild-bird dataset and uses two focal PubMLST examples:

- **46556 / P3-2209 / ST2209 / ST-179 complex** — bird-associated lineage;
- **46122 / KAI44/12 / ST45 / ST-45 complex** — generalist lineage.

See [`../instructor/slide_map.md`](../instructor/slide_map.md) for the full slide-by-slide teaching map.

The previous generated `wild-bird-amr-workshop-*.pptx` files have been removed because they no longer match the session actually delivered. The screenshot-rich PowerPoint source (`pubMLST_intro_WB`) is maintained separately; the workbook and instructor notes here reproduce the practical workflow exactly.
