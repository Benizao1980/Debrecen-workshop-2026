# Change log — public-data edition

This edition replaces the earlier workshop draft that used genomes from an active livestock–wildlife project.

## What changed

- Removed all Swedish livestock–wildlife project isolate identifiers, metadata and figures.
- Rebuilt the core mystery-genome practical around the published Arning et al. (2021) source-attribution dataset.
- Added deterministic selection of four public teaching cases: wild-bird specialist, chicken specialist, ruminant specialist/near-specialist, and ecological generalist.
- Added a small public reference panel drawn from the published training set.
- Added a reproducible setup script that records PubMLST IDs and can attempt to retrieve public assemblies from the PubMLST REST API.
- Reframed source attribution around the specialist–generalist contrast and model uncertainty.
- Replaced the AMR section with the published Mourkas et al. (2024) wild-bird microbiome/AMR study and its public Figshare assemblies.
- Rebuilt the slide deck from scratch so no sensitive figures or project-specific results remain.
- Kept precomputed-result templates so the session can still run without reliable workshop Wi-Fi.
