# Changelog

## 2026-09-19 — aligned to the deck actually used in Hungary

Rebuilt the workshop around `pubMLST_intro_WB.pptx` and the Mourkas et al. (2024) public wild-bird dataset.

### Removed from the live training workflow

- the Arning et al. 2021 source-attribution dataset as the core practical;
- the four anonymous/mystery-genome exercise;
- synthetic A/B/C/D mystery roles;
- scripts for generating/downloading mystery genomes;
- unpublished/sensitive livestock–wildlife example data and figures;
- claims that participants run a formal supervised source-attribution model during this 2-hour session.

### Added / updated

- the Mourkas et al. 2024 **700-genome** wild-bird collection as the single core dataset;
- exact PubMLST workflow shown in the delivered slides;
- metadata exercises using `country`, `continent`, `source` and `comments`;
- exact focal isolates from the live demo:
  - PubMLST **46556 / P3-2209 / ST2209 / CC179**;
  - PubMLST **46122 / KAI44/12 / ST45 / CC45**;
- specialist/generalist comparison built around those records;
- a 17-isolate copy/paste panel drawn from records visible in the slides plus the two focal isolates;
- Genome Comparator and Microreact instructions matching the live demonstration;
- participant workbook, quick reference, instructor run sheet, slide map and answer key;
- slide-aligned participant/instructor materials and a slide map; the screenshot-rich PowerPoint source is maintained separately from the repository.

## 2026-09-16 — first public-data edition

The earlier public-data edition removed active Swedish livestock–wildlife project genomes and rebuilt the draft practical around the published Arning et al. (2021) source-attribution dataset plus the Mourkas et al. (2024) AMR case study. That structure has now been superseded by the 2026-09-19 revision above.
