# Pre-workshop checklist

## One week before

- [ ] Run the public-data setup script.
- [ ] Confirm all four FASTAs open and are public records.
- [ ] Test PubMLST sequence query with mystery A.
- [ ] Run Genome Comparator once on A–D + reference panel.
- [ ] Save precomputed results.
- [ ] Check the live PubMLST interface has not materially changed.
- [ ] Verify repository links/DOIs.

## Day before

- [ ] Download a local ZIP copy of the repository.
- [ ] Put A–D FASTAs on the teaching laptop.
- [ ] Keep answer key in a separate/hidden folder.
- [ ] Open PubMLST and workshop pages in browser tabs.
- [ ] Have the slide deck locally (not cloud-only).

## In the room

- [ ] Test Wi-Fi.
- [ ] Put repo/ZIP link on screen.
- [ ] Pair participants if laptops/network are limited.
- [ ] Switch to precomputed outputs quickly if a web job stalls.
