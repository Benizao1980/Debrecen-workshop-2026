# Pre-workshop checklist

## One week before

- [ ] Confirm the live PubMLST interface still exposes the Mourkas et al. 2024 publication filter.
- [ ] Confirm the filtered collection returns **700 genomes**.
- [ ] Open focal isolates **46556** and **46122** and check their records/classification context.
- [ ] Run the 17-isolate Genome Comparator panel once using **C. jejuni / C. coli cgMLST v2**.
- [ ] Test the Microreact export workflow.
- [ ] Verify repository links and DOIs.

## Day before

- [ ] Download a local ZIP copy of the repository.
- [ ] Have `participants/genome_comparator_panel.txt` ready to paste.
- [ ] Keep the answer key in a separate instructor-only tab/folder.
- [ ] Open PubMLST and workshop pages in browser tabs.
- [ ] Have the 36-slide `pubMLST_intro_WB` deck stored locally, not cloud-only.
- [ ] Keep screenshots in the deck available as the fallback if Wi-Fi or web jobs stall.

## In the room

- [ ] Test Wi-Fi and PubMLST login.
- [ ] Put the repository link on screen.
- [ ] Pair participants if laptops/network are limited.
- [ ] Move on quickly from a slow Genome Comparator/Microreact job and teach from the slide screenshots if needed.
