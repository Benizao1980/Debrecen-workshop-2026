# PubMLST wild-bird practical — quick reference

## Dataset
Filter publication to:

`Mourkas et al. 2024 Curr Biol 34:3955–3965.e4`

Expected dataset: **700 genomes**.

## Useful PubMLST routes

- **Modify form → Filters**: filter by publication
- **Breakdown → Two Field**: compare metadata fields
- **Customise → General options**: add `comments` to result table
- **click isolate ID**: full isolate record + classifications
- **Analysis → Genome Comparator**: gene-by-gene/cgMLST comparison
- **External → Microreact**: tree + map + metadata visualisation

## Interpretation ladder

**metadata → MLST/ST → CC → cgMLST relatedness → ecological association → transmission hypothesis**

Do not skip steps.

## Three warnings

1. PubMLST submissions are not a random sample of nature.
2. A shared ST/CC does not prove recent transmission.
3. Source attribution estimates affinity to sampled populations; generalist lineages can be genuinely ambiguous.
